## Статус: вертикальный срез в разработке

### Реализовано

**Игрок (`player.tscn`)** — CharacterBody2D
- Платформенное движение: горизонтальное перемещение + гравитация + прыжок
- Двойной прыжок через счётчик `jumps_used`/`max_jumps` (не через bool-флаг)
- Рывок (dash) с длительностью и кулдауном, во время рывка гравитация игнорируется
- Атака: широкая capsule-хитбокс (AttackHitbox/Area2D) перед игроком, включается на attack_duration
- Комбо на 3 шага через explicit-переменные (combo_step, combo_reset_timer) — НЕ State Machine, т.к. состояний пока мало
- Input Actions: move_left/right, jump, dash, attack (не хардкод клавиш)
- Игрок состоит в группе "player" (через add_to_group в _ready(), не через редактор)

**Враг (`enemy.tscn`)** — CharacterBody2D
- DetectionZone (Area2D) обнаруживает игрока по группе "player", включает преследование
- Простое преследование по горизонтали через sign() направления к игроку
- Hurtbox (Area2D) в группе "enemy_hurtbox", метод take_damage(amount) → queue_free() при health <= 0

**Арена (`arena.tscn`)** — Node2D, назначена как Main Scene
- Sprite2D-фон (временный арт, нарисован пользователем)
- Floor: StaticBody2D + ColorRect-заглушка
- Player и Enemy вложены как экземпляры сцен

### Ключевые архитектурные решения
- Hitbox/Hurtbox паттерн через Area2D — отделён от физических CollisionShape2D тел
- Группы (Groups) вместо жёстких путей к узлам (get_node) — слабая связанность
- queue_free() вместо free() — безопасное удаление в конце кадра
- Явная типизация вместо `:=` там, где тип неоднозначен (например, sign())
- @export для дизайнерских параметров — подбираются в инспекторе без правки кода
- State через явные переменные, а не Finite State Machine — осознанная отсрочка усложнения

### Известные временные решения (техдолг, осознанный)
- Fallback-визуал: заглушки вместо анимированных спрайтов (icon.svg, ColorRect)
- AttackHitbox — капсула вместо истинной дуги атаки
- Background Sprite2D имеет ненулевой Position (артефакт ручной подгонки)
